# 这个项目是什么？

1. 一个面向高校/线上组织/等等形式的交流平台。
2. 你可以在这个平台上查看自己感兴趣的社团/组织，查看一些公开或者参与组织的活动安排，与其他人在线交流，分享自己的事情。

# 这个项目面向谁？

1. 你是一个想要参与组织的人，但是因为平时的社交平台中并没有明显的组织活动，你没办法直接寻找是否有同好能够参与其中
2. 你是一个想要寻找他人参与自己组织的人，你开创了一个社团/组织，但是苦于没有宣传渠道，平时宣传也没有人响应。

# 第一版做成什么样子？

用户创建账号，进入平台之后。能够在一个公共的大型频道里面发言。你可以在这里直接与别人聊天，也可以宣传自己的组织，或是寻找感兴趣的组织。
同时，你可以在一个全部社团介绍页面，快速的过滤，搜索你感兴趣的社团，并查看它公开的活动安排以及相关情况，并尝试加入频道或者联系他。
你也可以创建自己的组织，维护自己的组织，发布公开或私人的活动安排，与同好方便的决定活动计划。
