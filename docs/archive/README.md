# Documentation Archive

This directory stores historical documents that no longer describe the active product model.

## Active model

The active first-version product model is Activity-first and is documented in:

- `VISION.md`
- `docs/MVP.md`
- `docs/adr/0003-activity-first-mvp.md`
- `README.md`
- `CONTEXT.md`
- `docs/roadmap.md`
- `docs/api-contract.md`
- `docs/manual-acceptance.md`
- `docs/deployment.md`

## Archive rule

Archived documents are reference material only. Do not use them as implementation requirements unless a new ADR explicitly reopens them.

## Archived groups

### `organization-first/`

Documents from the previous Organization-first product framing. These are historical after ADR 0003.

### `teaching-platform/`

Original school/course/class channel design.

### `pre-organization-pivot/`

Root docs and feature docs from before the organization-platform cleanup:

- `pre-organization-pivot/README.teaching-platform.md`
- `pre-organization-pivot/api-contract.teaching-platform.md`
- `pre-organization-pivot/manual-acceptance.teaching-platform.md`
- `pre-organization-pivot/product-engineering-map.teaching-platform.md`
- `pre-organization-pivot/features/`

### `deployment-history/`

Historical deployment notes. These may contain old query-userId, school/course channel, or Organization-first examples and are not current deployment acceptance.

### `feedback-history/`

Historical validation notes.

### `misc/`

Temporary or one-off historical notes.
